# Mārtiņš Girss

I build automation systems that run small businesses without me.

Based in Norway. Founder of [Children's Joy](https://childrensjoy.io), a nonprofit publishing
free educational books for children — which is also where most of this tooling was born,
because a one-person organisation has to automate or stop.

Before this I spent 15+ years managing construction and reconstruction projects end to end,
so the automation I write is aimed at the parts of a business that actually cost time:
bookkeeping, invoicing, procurement, market research, reporting.

### What I've built

- **[conta-accounting-automation](https://github.com/martinsgirss/conta-accounting-automation)** — PowerShell tooling for the Conta API that books entries,
  issues invoices and pulls PDFs for a Norwegian AS. Monthly bookkeeping went from a full
  day to under an hour.
- **[gmail-invoice-mcp](https://github.com/martinsgirss/gmail-invoice-mcp)** — an MCP server that pulls invoice attachments out of Gmail
  and files them into an accounting folder. Fills the gap every standard Gmail integration
  leaves open.
- **[etsy-demand-radar](https://github.com/martinsgirss/etsy-demand-radar)** — eleven Python modules that decide what to design next from live
  Etsy API data, replacing a paid research subscription and a lot of guessing.
- **[mt5-mcp-server](https://github.com/martinsgirss/mt5-mcp-server)** — an MCP server for the MetaTrader 5 terminal: historical data,
  real-time quotes, order handling and backtesting, with a separate safety layer.

Two live WordPress sites are also mine — [childrensjoy.io](https://childrensjoy.io),
trilingual with custom plugins for an in-browser book reader and language switching,
and [silentcampexpeditions.com](https://silentcampexpeditions.com), delivered for a client.
